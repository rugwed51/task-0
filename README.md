## Setup Instructions

### Prerequisites
Ensure you have **Python 3.8+** installed on your system.

### 1. Clone or Extract the Project
Open your terminal or command prompt and navigate to the project directory:
```bash
cd path/to/your/project-folder
```

### 2. Create a Virtual Environment (Recommended)
Isolate your project dependencies by creating a virtual environment:

* **Windows:**
  ```bash
  python -m venv venv
  venv\Scripts\activate
  ```
* **macOS/Linux:**
  ```bash
  python3 -m venv venv
  source venv/bin/activate
  ```

### 3. Install Dependencies
Install all required libraries, including NumPy, Pandas and Matplotlib.

## Commands to Run the Solution

To execute the main python script and generate the analysis results, run:
```bash
python main.py
```
